# CPP Modules 00–05

A series of exercises introducing C++ fundamentals and object-oriented programming.

| Module | Topic | Grade |
|--------|-------|-------|
| CPP00 | Namespaces, classes, member functions, stdio streams, initialization lists | 100/100 |
| CPP01 | Memory allocation, pointers to members, references, switch statement | 100/100 |
| CPP02 | Ad-hoc polymorphism, operator overloading, Orthodox Canonical Form | 80/100 |
| CPP03 | Inheritance | 100/100 |
| CPP04 | Subtype polymorphism, abstract classes, interfaces | 80/100 |
| CPP05 | Exceptions, try/catch | 100/100 |

## Overview

Each module contains multiple exercises (`ex00`, `ex01`, ...) that progressively cover C++ concepts from basic class design to advanced OOP patterns.

## Build

```bash
cd CPP0X/ex0Y
make
```
