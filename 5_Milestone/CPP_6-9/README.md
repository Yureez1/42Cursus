# CPP Modules 06–09

Advanced C++ modules covering type casting, templates, containers, and the STL.

| Module | Topic | Grade |
|--------|-------|-------|
| CPP06 | C++ type casting (`static_cast`, `dynamic_cast`, `reinterpret_cast`) | 100/100 |
| CPP07 | Templates (function and class templates) | 100/100 |
| CPP08 | Templated containers, iterators, algorithms | 100/100 |
| CPP09 | STL containers (solving real problems with the right container) | 100/100 |

## Overview

These modules focus on writing generic, efficient C++ code using templates and the Standard Template Library.

## Build

```bash
cd CPP0X/ex0Y
make
```
